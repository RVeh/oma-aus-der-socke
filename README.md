# 🧦 Hol OMA aus der Socke

Materialien zur Modellierung und Simulation von Wartezeiten beim zufälligen Ziehen von Buchstabenfolgen.

Das Repository ergänzt den Artikel **„Hol OMA aus der Socke“**. Es enthält GeoGebra-Dateien, Python-Notebooks und begleitende PDF-Dokumente. Die Materialien zeigen verschiedene Modellierungen des Zufallsexperiments und stellen Wege zur Simulation, rekursiven Berechnung und exakten Auswertung bereit.

---

## 🚀 Direkt starten mit Binder

Die Python-Notebooks können ohne lokale Installation direkt im Browser geöffnet werden:

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/RVeh/oma-aus-der-socke/HEAD)

Nach dem Start von Binder im Menü

`Run` → `Run All Cells`

auswählen, um ein Notebook vollständig auszuführen.

Der Start von Binder kann einige Zeit dauern.

## 📁 Struktur des Repositories

| Ordner       | Inhalt                                                                            |
| ------------ | --------------------------------------------------------------------------------- |
| `geogebra/`  | GeoGebra-Dateien zu den verschiedenen Modellierungen                              |
| `notebooks/` | Python-Notebooks für Simulationen, rekursive und exakte Berechnungen              |

---

## 🧮 GeoGebra-Dateien

Die GeoGebra-Dateien dienen vor allem der schulnahen Simulation und Visualisierung der verschiedenen Modelle.

Ein zusätzliches PDF dokumentiert zentrale GeoGebra-Befehle, die für die Umsetzung benötigt werden. Dabei wird exemplarisch gezeigt, wie Simulationsergebnisse gesammelt, grafisch dargestellt und durch Kenngrößen ausgewertet werden können.

---

## 🐍 Python-Notebooks

Die Python-Notebooks ergänzen die GeoGebra-Dateien. Sie ermöglichen unter anderem:

* Simulationen der Wartezeiten,
* rekursive Berechnungen der Verteilungen,
* exakte Berechnungen für ausgewählte Modelle,
* grafische Darstellungen der Ergebnisse.

Die Notebooks können entweder lokal mit Jupyter oder direkt über Binder ausgeführt werden.

---

## 📄 PDF-Dokumente

Die PDF-Dateien enthalten ergänzende Darstellungen zu den mathematischen Hintergründen, insbesondere zu

* erzeugenden Funktionen,
* rekursiven Verfahren,
* Matrixdarstellungen,
* zentralen GeoGebra-Befehlen.

Sie sind als Zusatzmaterialien zum Artikel gedacht.

---

## Hinweis

Die Materialien richten sich an Lehrkräfte, die die Modellierungen im Unterricht oder zur eigenen Vorbereitung nachvollziehen, anpassen oder weiterentwickeln möchten.
